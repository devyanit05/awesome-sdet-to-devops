# 🚀 Awesome SDET to DevOps

> A practical roadmap for Software Test Engineers transitioning into DevOps Engineering.

This repository documents everything I'm learning while moving from **Software Development Engineer in Test (SDET)** to **DevOps / Platform Engineering**.

Instead of collecting certificates, I'm building projects, documenting concepts, writing notes, and sharing everything publicly.

Whether you're an Automation Engineer, QA Engineer, or SDET looking to make the same transition, I hope this repository helps.

---

# 🎯 Goals

- Learn DevOps through projects
- Build production-inspired systems
- Understand cloud-native architecture
- Document every important concept
- Crack DevOps interviews
- Help other SDETs transition into DevOps
